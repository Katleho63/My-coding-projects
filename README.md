# My Coding Projects 💻

## 📘 Overview
This repository contains a collection of coding and system design projects developed as part of my Bachelor of IT in Business Systems program.  
It showcases my practical experience in **Human-Computer Interaction (HCI)**, **Website Development**, and **Front-End Prototyping** using HTML, CSS, and JavaScript.  

Each project demonstrates creativity, problem-solving, and usability design principles applied in real-world contexts.

---

## 🎯 Objectives
- To display front-end coding and web design skills.  
- To document Human-Computer Interaction (HCI) prototypes developed during coursework.  
- To showcase real client projects, including Downlow Construction and Projects.  
- To highlight how IT and business requirements are aligned in system design.
